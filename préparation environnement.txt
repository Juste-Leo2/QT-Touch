### Étape 1 : Mettre à jour et installer les pré-requis

Ouvre ton terminal sur le Raspberry Pi et lance ces commandes pour t'assurer que tout est à jour et que les bibliothèques nécessaires sont installées.

```bash
sudo apt update
sudo apt full-upgrade -y
sudo apt install python3-gpiozero python3-lgpio
```

*Note : Sur Raspberry Pi OS "Bookworm" (la version par défaut du Pi 5), il est recommandé d'utiliser les paquets système (`apt`) comme ci-dessus plutôt que `pip` pour éviter les erreurs d'environnement virtuel.*

### Étape 2 : Le branchement (Vérification)

Assure-toi que ton câblage est complet. Outre tes GPIOs de données, n'oublie pas l'alimentation :

*   **VDD** et **VREF** du MCP3008 -> **3.3V** du Pi (Pin 1 ou 17)
*   **AGND** et **DGND** du MCP3008 -> **GND** du Pi (Pin 6, 9, etc.)
*   **CLK** -> GPIO 12
*   **DOUT** -> GPIO 16 (C'est le MISO)
*   **DIN** -> GPIO 20 (C'est le MOSI)
*   **CS/SHDN** -> GPIO 21
